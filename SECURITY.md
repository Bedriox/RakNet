# Security Policy

Bedriox/RakNet is pre-release software and no version is currently supported for production use.

Do not disclose suspected vulnerabilities in public issues, discussions, pull requests, chat rooms, or packet fixtures. Report them privately to the Bedriox team using the security contact published at [bedriox.com](https://bedriox.com). Include the affected revision, impact, reproduction steps, and any proposed mitigation. Avoid sending live credentials, personal data, or destructive proof-of-concept traffic.

The team will acknowledge a complete report when operationally possible, investigate it, coordinate a fix and disclosure, and credit reporters who request credit. No response-time or bounty commitment is made during private foundation development.
